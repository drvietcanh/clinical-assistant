# 📁 Thư Mục Tiến Trình Dự Án

Thư mục này chứa các file theo dõi tiến trình, kế hoạch và tổng hợp công việc của dự án.

## 📂 Cấu Trúc Thư Mục

```
docs/progress/
├── plans/          # Các file kế hoạch (KE_HOACH_*.md)
├── tracking/       # Các file tiến trình (TIEN_TRINH_*.md)
├── summaries/      # Các file tổng hợp (TONG_HOP_*.md)
└── README.md       # File này
```

## 📋 Quy Ước Đặt Tên

### Kế Hoạch (Plans)
- `KE_HOACH_[TEN]_YYYY-MM-DD.md` - Kế hoạch cụ thể
- Ví dụ: `KE_HOACH_TIEP_THEO_2026-01-XX.md`

### Tiến Trình (Tracking)
- `TIEN_TRINH_[TEN]_YYYY-MM-DD.md` - Tiến trình cụ thể
- Ví dụ: `TIEN_TRINH_TONG_HOP_2026-01-XX.md`

### Tổng Hợp (Summaries)
- `TONG_HOP_[TEN]_YYYY-MM-DD.md` - Tổng hợp công việc
- Ví dụ: `TONG_HOP_CONG_VIEC_2026-01-XX.md`

## 🔄 Cách Sử Dụng

1. **Kế hoạch mới**: Tạo file trong `plans/`
2. **Cập nhật tiến trình**: Tạo/cập nhật file trong `tracking/`
3. **Tổng hợp**: Tạo file trong `summaries/`

## 📝 Lưu Ý

- Luôn cập nhật ngày tháng trong tên file và nội dung
- Giữ file README này được cập nhật khi có thay đổi cấu trúc
- Các file cũ có thể được lưu trong thư mục `archive/` nếu cần
