## 📝 LƯU Ý KỸ THUẬT

### **Cấu Trúc Dữ Liệu:**
- `vietnamese_name`: Danh sách biệt dược cách nhau bằng dấu phẩy
- Format: `"Tên generic, Biệt dược 1, Biệt dược 2, ..."`
- Search function tự động tìm trong `vietnamese_name`

### **Ví Dụ:**
```python
"Ceftriaxone": {
    "vietnamese_name": "Ceftriaxone, Rocephin, Oritaxim, Cefaxone, Triaxone, Ceftri, Rophin",
    ...
}
```

Khi user tìm "Rocephin" hoặc "Cefaxone" → sẽ tìm thấy Ceftriaxone
