## ⌨️ COMMON TASKS

### Add New Phase
```
1. Phases tab
2. "➕ Add New Phase"
3. Fill form
4. Submit
```

### Update Progress
```
1. Phases tab
2. Expand phase
3. Adjust slider
4. Click "💾 Save"
```

### Add Update
```
1. Settings tab
2. "📝 Add Project Update"
3. Fill details
4. Submit
```

### Export Data
```
1. Settings tab
2. "📥 Export Data"
3. Download JSON
```
