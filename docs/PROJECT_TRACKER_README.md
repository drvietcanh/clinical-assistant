## 🚀 GETTING STARTED

### Step 1: Run the App
```bash
cd "d:\1 medical"
python -m streamlit run app.py
```

### Step 2: Access Project Tracker
- Open browser (usually http://localhost:8501)
- Click **"📊 Project Tracker"** in sidebar

### Step 3: Start Tracking
- View Dashboard for overview
- Add/edit phases in Phases tab
- Track updates in Settings tab
